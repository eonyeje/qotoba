# Qotoba

**Your words become the program.**

Qotoba is a meta-language, an agentic coding toolchain and an IDE built for working with coding agents. You describe software in a modern dialect of the language you already think in; Qotoba understands it, generates and maintains the code behind it, and gives you optional visual code-gen tools for the simpler parts.

> *Qotoba* comes from the Japanese 言葉 (kotoba), "words". The Q marks it as part of the Qotoba family, the successor to the projects previously known as Jargon, Dialect and Quanta.
>
> Pronounced **KO-to-ba**.

## Status

Pre-alpha. This repository is the public home of the project; the design is being moved here from private prototypes.

## What Qotoba is

- **A meta-language.** A compact, human-readable dialect that captures intent, structure and constraints, compiled to conventional code in target languages.
- **Agent-native tooling.** The language, its IDE and its toolchain are designed around a loop where coding agents do the heavy lifting and the programmer directs, reviews and refines.
- **Modern IDE UX.** An editor experience built for productivity with agents: live code-behind views, generated UI tools for simple code work, and a model of the program that both humans and agents can read.
