Qotoba Name Screen

Fifty-three candidate names screened in one pass against GitHub, npm, crates.io, PyPI and four domain endings. The result fed the naming decision.

Method

Each candidate came from a real word (Zulu, Xhosa, Swahili, Somali, Amharic, Quechua, Japanese, Korean, Tamil, Malay, Turkish, Georgian, Greek, Latin) or a mutation of an English word about language, with a Q or X swapped in. Every name was checked the same way, by direct lookup rather than search:

  • Registries: the public JSON endpoints of npm, crates.io and PyPI. A 404 means free.
  • GitHub: a load of github.com/<name> after the API rate limit ran out; a 404 means neither a user nor an org holds it.
  • Domains: RDAP, which is the registries' own protocol. Verisign for .com, Google for .dev, Identity Digital for .io, rdap.org for .ai. A 404 means unregistered.

The first parallel run tripped rate limits on GitHub and the RDAP relay, so GitHub and domains were re-run one at a time and the .com results were cross-checked against Verisign directly. The matrix below is the corrected run. Trademark databases were not part of this screen; the shortlist was searched on the web separately.
