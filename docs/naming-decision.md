# Qotoba, naming decision (2026-11-05)

Public name for the project formerly code-named Quanta 2.0 (earlier names: Jargon, Dialect).

Origin: Japanese 言葉 kotoba, "words / language", with the Q swap that marks the project family.
Pitch: your words become the program. A meta-language plus agentic coding plus an IDE that understands your dialect.

## Namespace scheme

- Product, CLI binary, language name: `qotoba`
- File extension: `.qt` is taken by Qt mental model; prefer `.qo` or `.qoto`
- GitHub: github.com/qotoba (org), repos `qotoba/qotoba`, `qotoba/ide`, `qotoba/docs`
- npm: `@qotoba/core`, `@qotoba/cli`, `@qotoba/ide`
- Domain: qotoba.dev (docs and site), qotoba.io (redirect), qotoba.ai (redirect)
- Company or community: Qotoba Labs
